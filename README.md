# Cloudy: Schedule Builder
Version: 0.2.1
العربية: ./README-AR.md

This website is a tool for generating multiple university schedules with the ability to filter and prioritize schedules over one another by scoring them. It can also display multiple schedules side by side for direct comparison, and lets you view all CRNs and copy them easily for later registration.

## How to Use
The page consists of four sections:
1. Header bar: Contains buttons for configuring the appearance and clearing preferences
2. Schedule filtering and sorting panel: From here you can select courses, set your preferences, and browse possible schedules
3. Schedule preview area: From here you can view the schedules you selected from the side panel side by side, export the schedule, or view the CRNs.
4. Footer bar: Notices and repository link
